Part 47 design board (Android 412x915 @3.5, light and dark). Static mock, not the built app.
- order: deck order = five themes, then 「一天」, then the relation card (last card, shown directly, no separate dice card).
- rel: 「瓜瓜和[小满 ▾]🎲之间有什么故事？」: main name fixed, partner is a tappable slot, 🎲 right beside it, ＋ below. No chip row, no explanation line.
- pick: tapping the partner name opens the list of other characters.
- group: ＋ adds people into the sentence, each removable (×). Two people -> ratings, three or more -> group story.
- day / dayopen: fixed card 「瓜瓜一天都在干什么？」 with six optional parts (早上 中午 下午 晚上 深夜 一整天的故事); ✓ marks a filled part; at least one needed to hand in.
board.html opens with ?s=<name>&t=dark.
