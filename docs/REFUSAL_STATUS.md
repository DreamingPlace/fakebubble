# Refusal codes and their HTTP status (Part 29 G)

One table, `apps/server/platform/web-refusal-status.ts`. 409 means "the state moved" and nothing else; a code that is not in the table answers 400 and is counted. Every literal `DomainError` code thrown under `apps/server` must be in it (`tests/web/unit/web-refusal-status-29.test.ts`).
